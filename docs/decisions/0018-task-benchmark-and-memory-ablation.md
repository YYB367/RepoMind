# 阶段目标：V2 以同一批代码任务测量记忆作用，保留失败和归因边界

2026-10-28，接受。原V1.2二十条检索题不能证明开发收益；本轮增加10个带真实Python源码和pytest的ParcelKit任务，6dev/4holdout。它是合成开发样例，不是生产仓库或SWE-bench。隐藏断言、项目历史、公开测试、参考补丁独立于产品输出手工指定；作者和实现者同会话，不声称独立盲测。

三组固定初始代码、模型、工具、步数和任务顺序。baseline不注入历史；memory从冻结“当前快照”读取事实；enhanced按任务as_of/known_at读取，并带同run之前通过任务的公开经验。当前快照与历史任务不一致是有意控制变量，不能把它描述成所有Memory Agent的必然缺点。时序和经验同时改变，不能分别宣称某一个带来的增益。

本轮使用任务显式事实键路由到已验收V1 resolver，避免把V1.2已发现的语义召回弱点混入代码执行比较。语义检索接口保留，未宣称修好了其主体歧义和未知拒答；V2.1再研究上下文方案。事实键路由不给金标代码或隐藏测试给模型。

每次试验使用独立Git样例副本和账本；项目source只读挂载进测试容器，模型修改经受限宿主工具完成。Agent只能反复运行公开测试；停止后才运行隐藏验收，结果不回流当前任务。参考回放三组使用相同人工解，只测管线，不用其100%成绩宣称真实模型收益。公开与隐藏测试共享Python进程，虽检查结束标记和用例数，但不声称可防御蓄意伪造pytest的恶意提交。

任务成功要求正常finish、实际源码变更、最终公开和隐藏测试都通过及范围完整性。代码断言失败、资源超限、提前退出都不能冒充通过；宿主引擎/清理等工程故障单列。报告成功率、重试率、工具拒绝、所有实际模型请求/usage和失败。已运行完比较不等于各任务全对，不预设增强组获胜。

dev可修协议，配置固定后首次holdout留档，不改金标或按holdout反复调参。冻结输入哈希、镜像ID、提示词hash和预算随报告保存。模型别名和网络/生成波动限制可重复性，少量任务不支持统计显著性或通用生产效果结论。

没有核心数据迁移；停用新基准即可回滚，旧三版数据和报告不重写。下一阶段边界仍是V2.1，不能以本轮优化为由提前接入。
