# ADR 0001：V1 使用确定性规则，不调用 LLM

- 状态：接受；日期：2026-10-26；范围：V1。
- 背景：同时调试抽取、召回和时序推断会使错误不可归因，模型服务还引入密钥、费用和随机性。
- 决策：仅导入人工结构化事件，以 Pydantic 2 校验，精确键检索，纯 Python 状态解析；不使用 LLM、Embedding 或自然语言自由问答。
- 替代方案：直接接入记忆 SDK 或模型抽取。推迟至独立版本评估。
- 后果：规则可复现、离线且易审计；输入整理成本由用户承担，字符串别名和语义相似无法自动处理。
- 验证：无 API 配置完成导入、查询和离线评测；运行依赖不含模型 SDK。
