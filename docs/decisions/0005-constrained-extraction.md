# 阶段目标：为 V1.1 增加受约束、可追溯的模型提取入口

ADR 0005；状态：接受；日期：2026-10-27；范围：V1.1。V1 的 ADR0001 保持有效历史，本决策只增加已获授权的新版本能力。

## 原方案与触发原因

V1 只导入人工结构化 JSONL，完全不调用模型。它使时间/状态规则可复现，但用户必须手工整理会话事实。V1.1 已获授权，需要将自然语言映射为候选事件，同时独立测量模型抽取错误。

## 替代方案比较

| 方案 | 收益 | 风险与代价 |
|---|---|---|
| 继续人工结构化输入 | 无模型错误、无需服务 | 不满足本次自然语言入口目标；仍保留为基线与兼容入口 |
| 模型直接更新记忆 | 链路短 | 模型可混淆计划/完成、项目和时间，无法可靠回溯；不采用 |
| 模型候选 + 本地验证 + 显式apply | 分离语言理解和确定性状态规则 | 需要审核工件、来源存储和分阶段评测；采用 |
| 全量引入记忆/Agent框架 | 可以提供更多组件 | 增加依赖与部署，超出本阶段最小边界；不采用 |

## 决策与原理

SourceMessage 可信 envelope 提供 project_id、source_id、observed_at 和原文；模型不能产生或覆盖这些范围字段。模型仅提出事实主体、属性、值、状态、可选生效时间/纠错目标及原文 evidence_text。

模型服务输出模式由显式配置决定：支持的 OpenAI 兼容服务可用 strict JSON Schema，DeepSeek 使用已核验的 JSON mode，再由本地 Pydantic 严格校验。详见 ADR0008。不能在失败后静默退回任意自由文本解析。

候选必须通过字段、时区、事件关系和精确原文片段检查；默认输出审核工件，显式apply才在同一事务写来源、事件、引文。correct 只指向已有同键同生效时间的非plan事件；候选省略effective_at时仅继承明确目标的时间。无法支持的日期和事实不猜测；模型拒答或截断产生可诊断结果。

模型的状态分类属于辅助建议；最终账本行为继续由 V1 resolver 决定。引用存在不等于语义正确，因此不能用“有引文”替代抽取质量评测。

## 取舍与影响

增加了模型延迟、调用费用和把文本发送给已配置服务的边界；用户需审阅候选。换来更低的人工结构化成本，同时保留原 V1 事件契约和可审计状态投影。模型和配置必须记录，密钥不进入工件、数据库和日志。

只用标准库 urllib 实现有限 HTTP 适配，不新增 SDK。这样请求和失败行为清楚，但本项目承担超时、响应解析及兼容性测试。不开启隐藏重试，不自动切换服务或模型。

## 迁移与回滚

结构化导入入口继续可用；自然语言入口写入 schema2 新表，见ADR0007。停用模型入口不删除既有事件；抽取错误用明确纠错事件修正。若回退到旧V1二进制，必须恢复schema1备份，不能仅撤回代码或改user_version。

## 验证

离线协议回放只证明工程契约；真实服务另测提取precision/recall、状态/时间/引用及拒答。项目串用须为0，原V1核心回归全过。真实模型未配置或未运行时，不宣称自然语言质量已验收。

接口依据：2026-10-27查阅 [OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=chat)，其他服务必须逐项核验实际能力。
