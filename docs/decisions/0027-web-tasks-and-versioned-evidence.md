# 阶段目标

通过本地网页执行真实开发任务，预览与候选一致的文件版本和任务差异，由用户审核后进入原账本，再由独立任务召回。

# ADR 0027：后台 Codex 包装器与项目内的版本化文本证据

状态：V4.3 采用；用户重启 Docker 后四项真实容器补验通过，最终全量 537 项通过。首次失败报告保留。

## 原方案与本轮变化

V4.1 网页只能审核和查询，开发任务还需手工运行包装器，来源仅有引文与路径。V4.3 保留原 Python HTTP 服务、SQLite、ReviewQueue 与 Codex 包装器，增加任务页和证据预览；不引入 Node 构建、前端框架、消息队列或第二套审核库。

后台线程适合单机单任务。SQLite 新增 web_tasks 保存状态和结果、web_task_candidates 关联候选、memory_review_notes 保存助手原始理由。文件租约与事务约束同库只有一个任务服务和一个活动任务。重复启动不会重复调用模型；服务重启将未结束任务标为 interrupted，禁止静默重跑。异常退出时仍需核对遗留 Codex 进程和文件。

选择先预查后启动，是为了让用户在花费额度与写文件之前看到项目、环境和将注入的已确认记忆。预查不调用模型，使用 Codex 自身 workspace 沙箱做本项目内的临时文件读写检查。点击启动后重新核对已确认记忆是否变化，使用预查的同一份事实列表。任务提示只有开发需求，结构化候选由包装器统一约定，助手据真实文件产出填写字段、引文和理由。

使用官方 codex exec --json 与 workspace-write。未增加危险绕过标志、未修改用户配置或 hook 信任。新版本 CLI 的具体能力以本机帮助、登录检查及真实文件修改验证为准，预查成功不能保证模型必然完成任务。[官方非交互文档](https://learn.chatgpt.com/docs/non-interactive-mode) · [官方 Windows 沙箱文档](https://learn.chatgpt.com/docs/windows/windows-sandbox)

## 版本、快照与差异

任务开始前读取登记项目的 Git 文件清单，包括允许范围的未跟踪文件；结束后再次取样。比较 SHA-256 得到该次任务的修改，而非把整个工作区相对 HEAD 的差异当作任务产出。完整文本单文件限 256 KiB，单次快照正文预算 4 MiB，最多检查 5000 个路径。超限/不支持类型保留有限元数据，差异标记不可完整生成；隐藏、凭据类、链接及工作状态路径排除。

候选绑定 Git 提交时，通过提交 blob 读取该版本并核对摘要与确切引文。文件候选优先选任务结束快照；没有快照时只使用与保存摘要匹配的当前文件，否则降级为保存引文。当前文件改变或缺失时提示范围和版本状态。预览不提供任意路径参数，只接收同项目候选 ID，再由已存来源决定路径。

Markdown、Python、JSON 和 txt 统一作为 UTF-8 文本显示，不使用 innerHTML 执行或渲染来源。引文用文本节点和 mark 高亮；正文和 diff 可键盘聚焦与滚动。预览独立于编辑表单异步读取，错误或重试只更新预览区。版本/引文匹配说明数据一致，不代替用户判断自然语言事实是否正确。

比较过直接打开磁盘路径、只显示 git diff HEAD、保存整个仓库及让模型重述来源。它们分别缺少范围限制、混入已有改动、存储过大或不能核对原文。限定快照和 Git blob 可以复用本机项目与原账本，保留可审查的字节证据。

## 兼容、迁移和回滚

SQLite user_version 仍为 2，仅增加三张表。理由使用独立表，不写入旧 candidate_json，避免旧版严格 schema 读不了新 JSON。确认事务、revision、事件及 provenance 不变；旧版 query/review 仍能读取正式记忆，旧程序不具备新任务管理能力。Git 的 safe.directory 只在明确登记/选择仓库的单次读取命令中指定，不改全局信任配置。

回滚先停止新任务服务，切回 v4.2.0 并启动原网页/CLI，继续使用同库。新任务表和理由表可保留，不删表或覆盖账本；来源快照仍可从任务回执取回。新任务没有自动提交、发布、确认记忆或修改默认 reference 策略。

## 证据及限制

真实任务 A 修改公共分页实现、测试和 ADR，自动提出候选；浏览器读取正确快照、原文高亮和三份差异。用户明确批准后网页确认，独立会话 B 从同库召回并应用该事实生成调用示例。旧 Git 来源也在真实浏览器读取。隔离测试覆盖失败、边界和恢复，网络拦截验证预览失败保留编辑。

单机服务无多人认证，模型可能未完成任务或不产生候选，状态“会话已结束”不自动等于需求验收通过。目前不提供实时逐命令日志或强制工具级只读文件清单；实际执行权限由 Codex 的项目沙箱承担。路径复用现有 ASCII 片段约束，中文文件名暂不支持。Git/CLI 登录及默认模型由本机配置提供。
