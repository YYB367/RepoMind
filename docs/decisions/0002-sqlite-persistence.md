# ADR 0002：使用 SQLite 持久化事件账本

- 状态：接受；日期：2026-10-26；范围：V1。
- 背景：本地小规模数据需要跨进程保留、唯一约束和批次回滚，不需要独立数据库服务。
- 决策：使用 Python 标准库 sqlite3、参数化 SQL、event_id 唯一约束、精确范围索引和显式事务。保存规范字段及原始 JSON。
- 替代方案：仅 JSONL 文件不便并发和唯一校验；PostgreSQL、Redis 与向量数据库增加部署负担。
- 后果：单文件可备份，无服务运维；不承诺大规模多写者或远程多租户。schema 必须有版本，未知版本不能自动销毁重建。
- 验证：独立 CLI 进程导入后查询；重复导入计数；非法批次无部分写入；同 ID 不同内容拒绝。
