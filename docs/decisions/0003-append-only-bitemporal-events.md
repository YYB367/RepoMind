# ADR 0003：保留事件历史与双时间语义

- 状态：接受；日期：2026-10-26；范围：V1。
- 背景：最后一条消息可能只是计划；迟到记录和纠错不能覆盖真实后续变更。
- 决策：保留全部事件，以 effective_at 表达事实生效，以 observed_at 表达观察。plan 不投影实际状态；correct 必须显式替代同键、同生效时间的非计划事件；不物理覆盖旧记录。
- 查询：as_of 选择有效历史，known_at 可选观察截止。同生效时间的不同值不按观察先后自动判胜，返回 insufficient_evidence；相同值联合证据。
- 纠错：一条 correct 只替代指定目标。平行纠错值不同仍冲突；纠错链按显式边处理。纠错不允许把 plan 升级为事实。引用需存在、不可跨键或成环。
- 替代方案：覆盖当前值会丢失历史；单时间字段无法回答“当时知道什么”。
- 后果：默认历史答案可能随迟到纠错改善；需要 known_at 才能复原当时知识。无隐式可信度评分，无删除/撤回事件类型。
- 验证：历史与当前、迟到纠错、纠错链、平行冲突、乱序导入、known_at 和计划测试。
