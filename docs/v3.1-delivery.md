# 阶段目标

用 RepoMind 自己作为首个真实试点，把「恢复提醒已经实现」和「默认执行策略仍是 reference」转为经过审核、可在后续独立进程中查询的项目记忆。

## 运行方法

从仓库根目录运行。安装命令为 python -m pip install -e .，或沿用本工作区的 Python 环境并将 PYTHONPATH 设为 src。完整真实试点需包含以下两个既有提交的 Git 历史。

~~~powershell
python scripts/check_v31_pilot.py capture --db work/v3.1/recheck.sqlite3 --output work/v3.1/recheck-capture.json
python scripts/check_v31_pilot.py verify --db work/v3.1/recheck.sqlite3 --output work/v3.1/recheck-verify.json
python -m repomind --db work/v3.1/recheck.sqlite3 query --project RepoMind --subject harness --field default_strategy --as-of 2026-11-06 --with-sources
~~~

capture 需要新库，verify 在独立进程读取同一个数据库。单条记录也可直接操作。下面的文件模式适用于源码压缩包，原始文件的记录时间由操作者提供。

~~~powershell
New-Item -ItemType Directory -Force work/v3.1 | Out-Null
$ledger = 'work/v3.1/manual.sqlite3'
$proposal = python -m repomind --db $ledger review propose docs/v3-recovery-delivery.md --project RepoMind --subject harness --field default_strategy --value reference --event-type declare --recorded-at '2026-11-05T17:15:18+08:00' --quote '恢复提醒加写入压缩未达到可复现改善门槛，实验保留原始流程。' | ConvertFrom-Json
$id = $proposal.candidate.candidate_id
python -m repomind --db $ledger review list --project RepoMind --status pending
python -m repomind --db $ledger review show $id --project RepoMind
python -m repomind --db $ledger review confirm $id --project RepoMind --revision $proposal.candidate.revision
python -m repomind --db $ledger query --project RepoMind --subject harness --field default_strategy --as-of 2026-11-06 --with-sources
~~~

Git 来源改用 --commit 加完整提交 ID，路径相对仓库根目录。可使用 --repo 指定仓库。原始文件与引文应匹配事实，审核前用 show 检查。修改用 review edit 配合 --revision 和 --value、--event-type 或 --effective-at。拒绝用 review reject 配合 --revision。确认或拒绝后可重复发送同一决定，数据库仍保留同一条审核记录。

## 技术原理和变更

本版用 Python 和现有 CLI 处理显式标注，以 SQLite 审核表保存草稿。Git 对象与原文摘要固定来源，文件模式可用于交付或测试记录。引文必须逐字存在于原记录。事实的含义由操作者审核。候选与正式账本隔离，只有 confirm 能将该候选写入正式账本。状态、来源和事件在同一事务提交。

首次接入审核命令时，数据库只增加审核表。原事件、来源和向量表无需迁移。程序回滚可使用原 V3 预览；需恢复到批准前的数据时，应还原完整数据库备份。旧程序可以查询已确认事件，审核界面和扩展来源视图由本版提供。实现原因、替代方案和时间语义详见 [ADR 0023](decisions/0023-explicit-review-before-ledger-write.md)。

## 文件变更

- memory/review.py 和 review_cli.py 实现来源核对、去重、审核状态和命令。
- adapters/sqlite.py 复用原事件写入校验，为确认事务提供同一写入边界。cli.py 增加 review 与 query --with-sources。
- tests/test_memory_review.py 验证审核、去重、跨项目隔离、旧库兼容和写入回滚。scripts/check_v31_pilot.py 提供两个独立试点阶段。
- reports/v3.1 保存真实试点回执与测试结果。旧冻结资料和实验报告保留。

本版验证显式 CLI 审核和独立进程的持久化。真实 Codex 跨会话召回属于 V4.0 验收。事实键和值由操作者指定，程序验证引文存在，语义是否支持结论由审核者判断。真实试点只覆盖 RepoMind。文件模式保存引用快照和摘要，日后核对完整原文仍需要保留原文件。
